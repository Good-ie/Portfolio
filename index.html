About Me

An engineer who ships real infrastructure.

I'm a Cloud & DevOps Engineer based in Lagos, Nigeria, with a passion for building cloud infrastructure and intelligent systems that work in the real world — not just in tutorials.

Problems I've Solved

Real problems. Real fixes.

Each project began with a specific pain point. Here's the problem, what I built, and the result.

Security01 · Nukreationz

Database passwords and keys living in code

ProblemHardcoded credentials are one leaked commit away from a breach.
SolutionIAM roles for EC2 plus AWS Secrets Manager, injected at deploy time.
ResultZero hardcoded credentials anywhere in the codebase or pipeline.
Delivery02 · Nukreationz

Slow, manual, error-prone deployments

ProblemEvery release meant SSH-ing into servers and hoping nothing broke.
SolutionGitOps pipeline in GitHub Actions: build → push to ECR → deploy to EC2, with DB migrations and health checks.
ResultA push to main ships automatically — with automated rollback if health checks fail.
Performance03 · Nukreationz

Bloated container images slowing every deploy

ProblemLarge images meant slower builds, pushes and pulls.
SolutionMulti-stage Docker builds that ship only what runs in production.
ResultImage size reduced by ~40%.
Reliability04 · Terraform

Click-ops infrastructure nobody could reproduce

ProblemConsole-built environments drift and can't be rebuilt reliably.
SolutionEverything defined in Terraform — networking, compute, databases, IAM.
Result20+ AWS resources provisioned from code, rebuildable on demand.
Scale05 · Blinko

A self-hosted app that needed to feel fast and trustworthy

ProblemA raw server IP is slow for distant users and has no HTTPS or brand domain.
SolutionCloudFront CDN + Route 53 custom domain + PostgreSQL on RDS with automated backups.
ResultGlobal HTTPS delivery on a custom domain, with data protected by backups.
ML / Automation06 · AI Trading Sentry

Emotional, inconsistent trading decisions

ProblemManual trading is inconsistent and risk is easy to mismanage.
SolutionXGBoost models across M5/M30/H1 confluence, 200 EMA trend filter and dynamic lot sizing.
ResultFully autonomous execution capped at 0.4% risk per trade, with a 24-hour kill switch and live telemetry.
Local Impact07 · Naija-speedtest

No clear picture of real network quality in Nigeria

ProblemUsers can't easily compare MTN, Airtel, Glo and 9mobile on real performance.
SolutionA real-time tester for download, upload, ping, latency and stability.
ResultAnyone can measure their connection and compare networks instantly.
People08 · Mentoring

Peers stuck on cloud tooling

ProblemDocker, Terraform and AWS feel intimidating without hands-on guidance.
SolutionHands-on training sessions built around real deployments.
Result5+ peers mentored and deploying on their own.
